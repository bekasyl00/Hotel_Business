# Кабинет сотрудников

Vue 3 + Pinia + Vue Router; FSD: app → pages → widgets → features → entities → shared. Интерфейс русский, i18n отложен. Существующий гостевой сайт остаётся основной точкой входа.

Рабочий интерфейс: спокойная плотная панель, тёмная зелёная навигация, светлая рабочая область, таблицы и отдельные формы. Сохраняем фирменный зелёный и Manrope существующего продукта. Первое действие администратора — создать санаторий; управляющего — открыть собственные бронирования. Номер — физическая комната с уникальным номером внутри санатория. Количество номеров считается из реестра, не задаётся несогласованным отдельным числом.

Целевые размеры: 1440x900 и 390x844. Таблицы прокручиваются внутри контейнера; на телефоне навигация компактная. Формы имеют подписи, клавиатурный фокус и native dialog. Удаление требует подтверждения; история доступна отдельно и не удаляется из интерфейса.

Состояния: загрузка — сообщение и блокировка повторной отправки; пусто — причина и кнопка добавления; ошибка — текст с возможностью повторить; частично — при сбое тайлов остаются поля координат; успех — уведомление и обновлённый список; ограничения роли — управляющий видит только свой санаторий, изменение чужого ID отклоняется демо-адаптером. Это не серверная защита.

Аккаунты в деморежиме выбираются без пароля. Настоящая авторизация и изоляция данных появятся на сервере. Демо-данные не должны содержать персональных данных реальных гостей. Все изменения локальные для браузера.
