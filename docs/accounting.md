# Как пользоваться бухгалтерией

Адрес: https://tynys-staff.vercel.app/staff/accounting. Вход для администратора и бухгалтера платформы. Бухгалтер видит все санатории, аналитику и план размещения; операции заселения/отмены/изменения каталога ему недоступны. Управляющий открывает документы только из карточки своей брони.

1. Выберите период, источник (`production`, банковский `sandbox` или `demo`) и при необходимости санаторий. Нажмите «Показать». Тестовые деньги не смешиваются с реальными.
2. Верхние суммы — зарегистрированные успешные поступления, возвраты и разница. Стоимость подтверждённых заказов, ожидание оплаты, неоплаченные оформленные заказы и расчётная комиссия показаны отдельно. Это не банковский остаток и не чистая прибыль. Комиссия до сверки возвратов; выплаты санаториям и сверка комиссий банков ещё не реализованы.
3. «Записать расход»: выберите платформу/санаторий, дату, целую сумму KZT, категорию и описание без персональных данных. Запись только учитывает расход, не переводит деньги. Исправление — отменить с причиной и внести новую запись. Отменённые записи остаются в истории и исключаются из итогов.
4. «Скачать финансовый отчёт XLSX» выдаёт три листа: сводка, санатории, расходы. Платформенные расходы без санатория вынесены отдельно. Отчёт ограничен 500 санаториями/200 расходами: при превышении нужно сузить фильтр. Реестр броней отдельно скачивается CSV (до 5000 строк). Это файлы сверки, не настроенный обмен с 1C.

## Документы из присланных шаблонов

Используются очищенные копии `сф1.xlsx`, `акт1.xlsx`, `пко1.xlsx` в `backend/commerce/accounting/templates`. Шаблон заполняется реквизитами выбранного санатория, именем гостя из снимка брони, датами/услугой, суммой, номером документа и выбранным режимом НДС. Оригинальные чужие персональные данные в шаблонах не сохранены. Файлы не содержат поддельных печатей/подписей.

- Акт и счёт-фактура автоматически становятся черновиками после зафиксированного выезда. Бухгалтер также может подготовить документ в реестре.
- «Просмотр» открывает PDF в кабинете. PDF/XLSX скачивают файл; после подготовки остаются «Скачать» и «Открыть файл» для повторного действия, в том числе на телефоне. Ошибка появляется рядом с кнопкой, а не наверху вне экрана.
- Черновик доступен сотрудникам. Для выдачи гостю нужны заполненные реквизиты, фактический выезд и полная сверенная оплата без незавершённого возврата. После выдачи снимок неизменяем: исправление через отмену и новую копию.
- Клиент: профиль → «Документы». Видны только выданные документы его собственных броней. Если их нет, показывается объяснение. На текущем стенде могут существовать только черновики: это не ошибка скачивания.
- ПКО пока остаётся черновиком: банковская оплата не доказывает получение наличных. Кассовый учёт ещё не подключён.

Эти PDF/XLSX — подготовленные неподписанные копии. Это не чек Kaspi/Halyk, не зарегистрированная ЭСФ и не замена официальной системе учёта. R20 в production-readiness.md содержит оставшиеся работы.

## Техническая админка

https://tynys-api.vercel.app/django-admin/ — вход активного superuser. На тестовом стенде логин `admin@tynys.test`; пароль находится только в игнорируемом локальном `backend/.env.stage.accounts`. Пароли не публикуются в документации/репозитории. Эта панель предназначена для безопасного чтения/диагностики; бизнес-изменения делаются в рабочем кабинете.
