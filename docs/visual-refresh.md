# Тыныс: визуальный стиль «Санаторный сад»

## Направление и границы

Обновление 2026-11-08: спокойный каталог отдыха и компактное рабочее пространство.
По уточнению пользователя убрана морская тема. Знак — три листа, символ спокойствия и восстановления; SVG работает как логотип и favicon.
Оливковый выделяет действия, молочный и тёплый каменный задают фон, небольшой охристый акцент дополняет палитру.
Баланс отдыха и оздоровления отражён в заголовках на RU / KK / EN; нет обещаний медицинского эффекта.

Исходный ориентир — существующие страницы проекта и предоставленный пользователем план размещения.
Никакие фотографии не объявляются реальными снимками санаториев: существующие подписи демонстрационных данных сохранены.

| Поверхность | Задача | Проверяемое решение |
| --- | --- | --- |
| Каталог | Найти санаторий, открыть профиль или карту | Поиск в первом экране; фото, название, цена в карточке; карта открывается прежней плавающей кнопкой |
| Санаторий / номер | Посмотреть медиа и выбрать даты | Крупная галерея, отдельные блоки описания и расчёта; контролы и порядок бронирования сохранены |
| Вход / профиль гостя | Войти и работать со своей историей | Контрастные поля, видимый фокус, единые кнопки; без изменений авторизации |
| Кабинет сотрудника | Быстро находить записи и действия | Светлая навигация, светлая рабочая область, компактные таблицы и сводки |
| План размещения | Различать состояния проживания | Синий бренд не меняет семантику: прошлые — фиолетовые, проживают — синие, забронированы — зелёные, ожидание оплаты — янтарное |
| Бухгалтерия / аналитика | Читать финансовые показатели | Чёткие заголовки, табличные цифры, горизонтальная прокрутка таблиц внутри контейнеров; финансовая таблица доступна с клавиатуры |

Целевые проверки: 1440×1000 и 390×844; русский, қазақша и English.
На телефоне карточки переходят в одну колонку, длинные меню прокручиваются внутри, горизонтального скролла всей страницы нет.
Анимация только у наведения; `prefers-reduced-motion` выключает её.

## Где изменять дизайн

- `src/app/styles/visual-theme.css` — общий слой оформления, подключён после исходных стилей в `src/app/main.js`.
- `public/assets/logo.svg` — векторный знак; прежний URL сохранён для всех существующих компонентов.
- `public/assets/botanical.svg` — декоративная иллюстрация первого экрана и входа сотрудников, без фактических данных.
- `index.html` — цвет браузерной панели.
- `src/pages/accounting/ui/AccountingPage.vue` — только `tabindex="0"` у прокручиваемой финансовой таблицы.

CSS не добавляет зависимости между FSD-срезами. Архитектура данных, маршруты, API, права и бизнес-правила не меняются. Изменены только три маркетинговые строки в каждой локали с сохранением ключей. Семантические цвета оплаты/проживания не переопределяются. Нет новых npm-зависимостей.
Токены `--green` / `--green-dark` сохранены как совместимые алиасы брендовых цветов для существующих компонентов; это не статусы бронирования.

## Параллельная работа

Работа выполнена в отдельном worktree `hotel_business-design`, ветка `codex/visual-refresh-20261108` от `f06f588`.
Обновления другого агента в аккаунтах, правах, профилях, навигации, локалях и backend не заменяются.
Редизайн оставлен в отдельной ветке для объединения после параллельной работы. Основная рабочая копия другого агента не изменяется.
Нативные приложения не пересобираются и не устанавливаются. Production-деплой не запускается из старого worktree: иначе он мог бы заменить параллельные функциональные изменения.

## Верификация

- `npm test`: 96 тестов и FSD-проверка.
- `npm run build`, `npm run build:surfaces`, `npm run arch:check`.
- 48 проверок страниц: каталог, санаторий, номер, регистрация, профиль, план размещения, аналитика и бухгалтерия × 3 языка × 2 ширины.
- Проверены поиск/сброс, открытие карты, Escape с возвратом фокуса, вход сотрудника, клавиатурный фокус и reduced motion.
- Проверены состояния загрузки, пустого поиска, ошибки с повтором, неполного каталога без цены и фотографии, успешного отображения данных, перенаправления неавторизованного сотрудника ко входу.
- Браузерные проверки используют только локальный demo transport и контролируемые ответы теста. Это не проверка настоящих оплат или production API.
- Локальные снимки и результаты: `output/design/` в worktree. Они не включены в Git.

Автоматическая проверка доступности axe: 0 нарушений WCAG A/AA на восьми проверенных страницах при обеих ширинах. Это не полная сертификация доступности. ECC evidence checker прошёл; наблюдения и снимки сохранены локально.

Общий демо-снимок тропического курорта заменён на вымышленный санаторий с зелёным двором. На карточках с этим изображением видна подпись об иллюстрации. Загруженные фото не меняются. Происхождение и точный запрос генерации: `docs/design-assets.md`.
