`npm test`: 5 тестов прошли. `npm run build`, `npm run arch:check`, `npm run arch:build`: успешно. Снимки и локальная запись проверки дизайна находятся в `output/playwright/` (не публикуются в Git).

Проверка адаптивности выполнена эмуляцией размеров Chrome, не на физических iPhone/Android. Полный аудит доступности не выполнялся. Серверное API, общая база, платежи и реальное наличие отсутствуют. Статический прототип опубликован на Vercel. Поток GitHub Actions добавлен; его результат следует проверять отдельно от локальных проверок.
