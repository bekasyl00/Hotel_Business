# Security review — 2026-11-11

Scope: local Tynys source, locked dependencies, isolated PostgreSQL regression suite. Method: testing-api-security-with-owasp-top-10 from https://github.com/mukul975/Anthropic-Cybersecurity-Skills (community project). No brute force, live payment mutations, customer-data extraction or production load tests.

## Confirmed findings and fixes

- npm advisory audit identified moderate dependency findings in glob/minimatch/rimraf. Compatible lockfile updates applied; post-fix audit reports zero known vulnerabilities. These are build/tooling dependencies, not proof of a remote compromise.
- pip-audit identified Pillow12.3.0 advisories (39 advisory entries, possibly overlapping identifiers). Upgraded to13.0.0. Audit of pinned requirements with --no-deps --disable-pip reports zero known vulnerabilities; this does not cover every transitive Python dependency.

## Source review

Reviewed native Bearer/cookie separation, managed media scope/publication, document ownership and spreadsheet formula handling, signed XPayment callback boundary. Existing tests exercise unauthorized/foreign access, credential invalidation, upload validation and payment/refund integrity. No additional exploitable application defect confirmed in this bounded review.

## Limits

Not a complete penetration test or guarantee of absence of vulnerabilities. Real SMS, production secret rotation for keys previously shared in chat, infrastructure permissions/backups and physical native-device testing remain separate requirements. No secrets were copied into this report.

## Validation

192 frontend tests and FSD passed; build, build:surfaces and arch:check passed. pip check passed. 374 backend tests on isolated PostgreSQL passed with Pillow13.0.0; migration drift check passed. No UI behavior change or native rebuild is required for these dependency fixes.
