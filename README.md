# Тыныс · санатории и рабочее пространство

Vue 3 · Pinia · Vue Router · Vite · Feature-Sliced Design. Русский интерфейс; i18n — позже.

[Сайт](https://vercel-site-puce-two.vercel.app/) · [Кабинет сотрудников](https://vercel-site-puce-two.vercel.app/staff/login)

- Гость: карта, санаторий, номер, тариф, даты, демо-бронь и отмена.
- Администратор: санатории с нуля, положение на карте, номера, тарифы, управляющие и история изменений.
- Управляющий: только закреплённый санаторий, его данные и бронирования.

Это фронтенд с демо-адаптером. Данные хранятся в браузере; демо-аккаунты выбираются без пароля. Настоящий бэкенд и авторизация ещё не подключены. Все цены, наличие, координаты и фотографии иллюстративные.

```sh
npm ci
npm run dev          # localhost:4173
npm test             # бизнес-правила, доступы, конфликты, FSD-импорты
npm run build        # только сайт → dist/site
npm run preview      # проверка собранного сайта, localhost:4174
npm run arch         # локальная интерактивная архитектура
npm run arch:check
```

Исходники: `src/app` → `pages` → `widgets` → `features` → `entities` → `shared`. Формы обращаются к асинхронному API-слою; для будущего сервера подготовлен HTTP-адаптер. [Контракт API](docs/api-contract.md), [решения](docs/decisions.md), [проверки](docs/verification.md).

Архитектура: `architecture/system.c4` описывает ответственность; `modules.c4` генерируется из реальных импортов Vue/JS. В деплой LikeC4 не входит. Vercel публикует только `dist/site`; GitHub Pages отключён.
