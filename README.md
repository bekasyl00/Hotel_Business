# Тыныс · санатории и рабочее пространство

Vue 3 · Pinia · Vue Router · Vite · Feature-Sliced Design · vue-i18n (русский, қазақша, English).

[Сайт](https://vercel-site-puce-two.vercel.app/) · [Отдельный кабинет сотрудников](https://tynys-staff.vercel.app/staff/login)

- Гость: карта и категории, профили санатория/номера с медиа, даты и тарифы, заявка с подтверждением, демо-оплата/возврат, отзывы после проживания, профиль и история квитанций.
- Администратор: санатории с нуля, положение на карте, номера, тарифы, управляющие и история изменений.
- Управляющий: только закреплённый санаторий, его данные и бронирования, заселение/выезд, модерация отзывов и аналитика.

Есть два режима: статическое демо и Django + DRF + PostgreSQL. В API-режиме работают пароли сотрудников, серверные данные и заявки с подтверждением управляющим. Опубликованный Vercel-сайт пока остаётся демо. Все цены, наличие, координаты и фотографии иллюстративные.

Гостевые аккаунты: телефон/пароль, регистрация и сброс с demo-кодом. В API-режиме история доступна после входа с другого устройства; статическое demo хранит данные только в браузере, отдельно для каждого адреса. Реальные SMS и Kaspi ещё не подключены: квитанции явно помечены как демо. Возврат рассчитывается от времени заезда, сохранённого в брони: от 48 часов — 100%, от 24 до 48 — 70%, менее 24 — 0%. [Возможности](docs/product.md) · [Что требуется до запуска](docs/production-readiness.md).

Отдельные iOS приложения: **Тыныс** для гостей и **Тыныс Команда** для сотрудников (Capacitor, разные bundle IDs и маршруты). [Запуск в Xcode и установка на iPhone](docs/ios.md). По умолчанию demo, без синхронизации между приложениями; Android пока не добавлен.

```sh
npm ci
npm run dev          # localhost:4173
npm test             # бизнес-правила, доступы, конфликты, FSD-импорты
npm run build        # только сайт → dist/site
npm run build:surfaces # public → dist/site, staff → dist/staff + проверка границ
npm run preview      # проверка собранного сайта, localhost:4174
npm run arch         # локальная интерактивная архитектура
npm run arch:check
```

Исходники: `src/app` → `pages` → `widgets` → `features` → `entities` → `shared`. Формы обращаются к асинхронному API-слою; HTTP-адаптер подключает Django API с cookie-сессиями и CSRF. [Запуск backend](docs/backend.md). [Контракт API](docs/api-contract.md), [решения](docs/decisions.md), [проверки](docs/verification.md).

Архитектура: `architecture/system.c4` описывает ответственность; `modules.c4` генерируется из реальных импортов Vue/JS. В деплой LikeC4 не входит. Vercel публикует отдельные артефакты `dist/site` и `dist/staff`; GitHub Pages отключён. [Сборки, сессии, локализация и будущие приложения](docs/frontend.md).

План завершения ведётся в [едином реестре R01–R34](docs/production-readiness.md): коммерческие и льготные процессы, документы, внешние подключения и критерии запуска. [SRE и масштабирование](docs/sre.md) — целевые требования и план испытаний, не подтверждённая производительность. Локально добавлены сезонные цены по ночам и включаемый сотрудником бесплатный тариф для детей до 3 лет; существующие брони сохраняют прежние условия.
