# Тыныс · санатории на карте

Прототип бронирования на HTML, CSS и JavaScript: карта, поиск по датам и гостям, категории номеров, тарифы, расчёт стоимости, локальные демо-брони и отмена.

[Сайт](https://bekasyl00.github.io/Hotel_Business/) · [Карта архитектуры](https://bekasyl00.github.io/Hotel_Business/architecture/)

Публикация через GitHub Pages: push в `main` запускает проверки, сборку и обновление сайта. Статус — GitHub Actions → `Publish prototype`. Локальный компьютер для работы опубликованного сайта не нужен.

Альтернатива: импорт этого репозитория в Vercel. `vercel.json` уже задаёт сборку и выходную папку `dist/site`; сначала требуется вход в аккаунт. Наличие конфигурации и ссылок выше само по себе не подтверждает успешный деплой — проверяйте результат публикации.

```sh
npm ci
npm start
```

Открыть http://127.0.0.1:4173. Сервер раздаёт статические файлы; API и бэкенда приложения нет.

```sh
npm test           # даты, пересечения, вместимость и стоимость
npm run build     # статический сайт в dist/site
npm run arch      # интерактивная карта архитектуры, адрес в терминале
npm run arch:check
```

Модель архитектуры: `architecture/system.c4`. Зависимости модулей: `architecture/modules.c4`, генерируются из кода командой `npm run arch:sync`. Решения: `docs/decisions.md`. Правила обновления: `AGENTS.md`.

Все цены, рейтинги и наличие демонстрационные, координаты приблизительные, фотографии иллюстративные. Подтверждение не создаёт настоящую бронь. Данные сохраняются только в localStorage текущего браузера; параллельное бронирование между устройствами не поддерживается. Карта требует подключения к интернету; список и выбор номеров работают при сбое тайлов. Публичная версия предназначена для демонстрации, не для реальных продаж.
