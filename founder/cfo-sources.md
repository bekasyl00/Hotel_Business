# Входы и происхождение

Единица — одна бронь. Валюта KZT. Доходная база для анализа — онлайн-наценка, НЕ полная стоимость отдыха; бухгалтерское признание выручки и налоги необходимо определить с бухгалтером по реальным договорам.

Подтверждено владельцем: 10% сверху для двух выбранных объектов; 0 согласившихся санаториев, 0 настоящих клиентских броней; бюджет неизвестен. 20 000 × 2 × 7 — пример из требований, не средний чек рынка.

Все три файла scenarios/*.json — НЕ прогноз: 3% платёжных расходов не тариф XPayment, 5% резерва не наблюдаемая частота возвратов, 2 000 поддержки не измеренный расход, 300 000 фиксированных/300 000 стартовых не бюджет владельца. Эти числа заданы только для чувствительности. CAC 0/8 000/18 000 — сценарии. При CAC=0 время органического маркетинга не бесплатно и должно войти в фактический учёт. Налоги, юридические услуги, SMS, сторы, серверы и зарплаты нужно раскрыть в настоящем бюджете; текущие сценарии их не оценивают по отдельности.

Расчёты выполнены функцией analyse из founder-cfo/unit_economics.py; результаты сохранены JSON. Корневой numbers.json намеренно не создан: подставлять предположения в официальный вердикт прибыли нельзя. Доходы/цены/доли панели не использованы как прогноз спроса.
